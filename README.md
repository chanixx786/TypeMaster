# Typing Test (Christian && Sef Production)

## Description

This project is designed to improve the typing speed and accuracy of individuals through
interactive, engaging exercises. The platform features several modules including typing
tests, tutorials, and games to make learning how to type fun and efficient.

## Technology Stack

### Frontend
- **Build Tool / Dev Server**: Vite
- **Library**: ReactJS
- **Styling**: Tailwind CSS

### Backend
- **Server-Side Platform**: Flask (Python)
- **ORM**: SQLAlchemy
- **Database**: PostgreSQL (Neon)
- **Third-Party AI Model**: Hugging Face

### QA / Automation
- **Framework**: Robot Framework
- **UI Automation**: Selenium
- **API Automation**: RequestsLibrary
- **Language**: Python

## Setup

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python run.py
```
